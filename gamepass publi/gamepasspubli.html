Xbox Game Pass

Game Pass es el servicio de suscripción mensual de Microsoft para videojuegos. Con Game Pass Ultimate puedes jugar en consola, PC y en la nube desde varios dispositivos. Esta versión está pensada para jugadores que buscan acceso completo a cientos de títulos, incluyendo lanzamientos desde el primer día, EA Play, multijugador en línea, recompensas y más.

Ventajas de Xbox Game Pass

  • Acceso a cientos de juegos de alta calidad para consola y PC.
  • Nuevos títulos de Xbox Game Studios disponibles desde el primer día.
  • Descuentos y ofertas exclusivas para miembros.
  • Juego en la nube desde distintos dispositivos.
  • Prueba juegos sin compromiso de compra.

El servicio incluye sagas populares como:

Call of Duty

DOOM Eternal

Forza Horizon 5
